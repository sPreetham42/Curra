# CURRA Graphify Context

This directory contains a curated repository knowledge graph report (`GRAPH_REPORT.md`) generated by Graphify.

## Purpose

- **Developer & Agent Orientation:** Provides a high-level overview of the repository's architecture, key components, module boundaries, and dependency flow.
- **Reduces Exploration Overhead:** Helps both human developers (especially frontend) and AI agents quickly understand the codebase structure without doing repeated, repository-wide manual explorations.
- **Stable Reference:** Provides a clean, sanitized snapshot of the system's current structural reality.

## Important Notes

- **Not the Source of Truth:** This is a *generated* artifact representing a snapshot in time. The actual source code and explicit architectural contracts (`contracts/`, `api/openapi.yaml`) remain the absolute source of truth.
- **Maintenance:** Regenerate this report (`python -m graphify extract .`) and update this directory only when the repository architecture changes materially (e.g., new core components, major refactoring, or boundary shifts). Do not commit the raw caches or temporary logs.
